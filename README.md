# Tecnofeudo

Año 2031: las tecnológicas son los nuevos señores feudales. Juego de cartas y rol ligero al estilo Munchkin, para 2 a 6 jugadores alrededor de una mesa de juntas, que se juega en el navegador.

- Multijugador P2P (PeerJS / WebRTC): quien crea la sala hace de anfitrión.
- Modo local contra bots: `?local=3`. Solo bots: `?demo=4`.
- Estático, sin dependencias de compilación.

Esta es una versión compilada y ofuscada para su distribución. El código fuente no se publica.

## Jugar

Con GitHub Pages activado: https://mtoromateos.github.io/tecnofeudo-play/

En local: `python -m http.server 8080` y abre `http://localhost:8080`.
